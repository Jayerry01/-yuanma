## 四、 核心手感算法与算式实证

1. **浮空力学方程 (`0x004D0540`)**:
   - 垂直分量固定添加 `+0.13f` 向上仰角（二进制常量位于 `0x005AA944`，在 `0x004D0674` 处由 `fadd` 累加）：$\vec{v}_{\text{impulse}} = (n_x \times 600.0,\; n_y \times 600.0,\; (n_z + 0.13) \times 600.0)$（`600.0f` 位于 `0x005AA934`，在 `0x004D0698` 处由 `fmul` 缩放）。平砍命中即可打出 $78.0\,\text{units/s}$ 微浮空，奠定挑空连招基础。
2. **两段式物理与跳跃 (`0x004CF5B0` / `0x005AA658` 槽位 86)**:
   - 高跳/冲刺跳速度 `375.0f` (`0x005AA940`)、轻跳速度 `282.0f` (`0x005AA93C`)、蹬墙仰角偏移 `1.0f` (`0x005A83F4`)、下身贴地射线深 `2.0f`、台阶容差 `10.0f`、躯干盒顶高 `32.0f`、水平半径 `8.0f`。
3. **搓招容差状态机 (`0x00488130`)**:
   - 32 槽环形队列，12 帧（400ms）超时容差窗口，前向滑动窗口回溯匹配 `AA`、`↓↑A`、`←→A`。
4. **武器扫掠盒 SAT 判定 (`0x004D2870` / `0x004D3634`)**:
   - 采样前后两帧的 `Dummy0/Dummy1` 形成 4 点空间薄片，与角色 AABB 盒进行 SAT 轴投影求交。
5. **追尾镜头防穿墙截断（重建推断参数 / 真实函数待重锚定）**:
   - 理想球面跟随距离 $180.0\text{f}$ (`0x005A84C0`)、障碍物避让截断 $5.0\text{f}$ (`0x005A8F74`)、极限贴近 $40.0\text{f}$ (`0x005A8E7C`) 在 `.rdata` 中物理存在，但原文档标注的 `0x004B6020` 实测为内存池节点分配器，故该组参数降级为**待重锚定的工程重建推断**。
6. **可行走坡度阈值 (`0x004CF005` / 二进制常量 `0x005AA92C`)**:
   - 常量 `0.42f` 位于 `.rdata:0x005AA92C`，在 `0x004CF005` 处由 `fcomp dword ptr [0x005AA92C]` 直接引用进行坡度法线余弦比较，$\arccos(0.42) \approx 65.16^\circ$（倾角 $\le 65^\circ$ 判定为可站立地面）。

## 五、 如何复现全部结果

本仓库**不提供**原版资产与反编译源码，但提供完整可复现的方法。您需要自备该游戏的**合法副本**。

```bash
# 1. 解包全部 28 个 .pak 封包（需自备原版安装目录）
python tools/pak_extractor.py --src "C:/Program Files (x86)/Meteor" --out ./out/pak

# 2. 解析动画 / 碰撞 / 几何 / 物品主表
python tools/amb_parser.py  ./out/pak/character.amb
python tools/cob_parser.py  ./out/pak/sn01/sn01/sn01.cob
python tools/gmb_parser.py  ./out/pak/sn01/sn01/sn01.gmb
python tools/res_parser.py  ./out/pak/Meteor.res

# 3. 招式派生状态机（character.act + p0.pos → 有限状态机）
python tools/act_pos_mapper.py ./out/pak/character.act ./out/pak/p0.pos
```

反编译层面需自行搭建 Ghidra Headless（12.1.x + JDK 21），使用 `tools/ExportAllCpp.java` 与 `tools/run_full_export.bat` 驱动全量导出，再用 `tools/split_full_decompilation.py` 按 12 模块分卷。

各格式的字段定义、魔数与算法细节见 `docs/`。
