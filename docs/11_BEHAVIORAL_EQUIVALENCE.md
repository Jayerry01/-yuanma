## 四、发散报告格式（逐项，禁抽查）

```
| 矩阵项 | 原版观测 | 克隆观测 | 判定 |
|---|---|---|---|
| T01 | moveState 0→1 @P2 | 同 | PASS |
| ... | | | FAIL / NOT-TESTED |
```

- **PASS**：两侧在同一语料相位产生同向观测；
- **FAIL**：同相位观测发散——记录两侧原始值；
- **NOT-TESTED**：语料未覆盖（补语料后重跑，禁止口头宣称等价）。
