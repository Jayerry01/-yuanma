## 三、三条判断（决定方案形状）

**1. 不能平推。** F 档 6,234 行只占 4.6% 字节，其中大半是 thunk（`jmp [iat]`）、空桩、单指令 getter。
逐条逆向的边际收益接近零。反向看，249 个 B 档函数平均 2,350 B，一个顶 100 个 F 档。

**2. 先证来源，再逆逻辑。** 静态链接的老游戏，CRT / D3DX / GSL / STL / JPEG 都在 `.text` 里。
这些不该手逆——按版本 + 函数指纹整块标注，比逐个读体更准也更便宜。
已证一例：**GSL 1.0**，64 行 / 13,364 B，镜像内 98 条 `E:\ftp\gsl-1.0\…` 源路径串，
已定名到函数级（`gsl_interp_alloc` / `cspline_alloc` / `gsl_interp_accel_alloc` /
`gsl_error` 四件套）。CRT 与 D3DX 尚未划界——这是 P1 的全部工作。

**3. 最大的函数就是系统。** 实测占位函数前十名：
