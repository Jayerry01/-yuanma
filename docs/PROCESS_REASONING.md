## 二、无 RTTI 下的类 / 虚表识别流程（精化操作）

1. **构造函数定位**：搜 `C7 01 <imm32>`（`MOV [ECX], vtable`）写入点，确定对象布局与基类。
2. **多虚表背靠背**：连续代码指针 run **≠ 单张虚表**；同一函数在 run 内不同子表槽位号不同（如 `0x5AA658` 槽 85 / `0x5AA6A8` 槽 65）。引用槽位必须同时标 **基虚表地址 + 偏移字节 + 解析后绝对 VA**。
3. **转发路由还原**：读 `[ecx+index]` 当前索引 + 机位数组 `[ecx+eax*4+base]` → `jmp [reg+disp8]`（3 字节编码 `FF 62 xx`，勿用 disp32 搜索）。
4. **交叉引用盲区**：单引用虚表槽位在常规 xref 中显示为 0，须**反向索引虚函数表**定位调用源。
5. **硬签名优先**：浮点常数（`0x5AA8E8`=0.11s、`0x5AA934`=600.0f）与 Win32 API（QPC/DirectInput）锚点，远比符号名可靠。
6. **字符串只作线索**：全镜像扫字符串极易把控制台/配置命令、调试字串、UI 渲染器误判为核心玩法；落结论前先与既有语义账本（semqueue Cite 列）对表。

## 三、已验证架构结论（相机域，最终）

- **CameraManager** 虚表 `0x5A9FE0`（225 方法）：slot[115]=`0x4BB4B0` SwitchExtraCamera，slot[69]=`0x004F0C50`。
- **ChaseCamera** 虚表 `0x5AB710`（28 项）：Update = slot[1] `0x004F5FA0`（3,248 B 大函数，高精度计时驱动）。
- **BaseCamera** `0x5AB670`，**ExtraCamera** `0x5AB7A8`。
- **转发链** `0x4BB4B0`：读 `[ecx+0x3F0]` 索引 + `[ecx+eax*4+0x3C8]` 机位数组 → `jmp [edx+0x44]` → `0x004F6C70` = SetExtraMode，写 `[ecx+0xA0]`。
- **`[EDI+0x2960]`** = `std::list<CameraManager*>`（副视口/多机位相机管理器链表）。GameApp ctor `0x487A67`/`0x487A86` 注册；slot[145]=AddCamera `0x00488330`、slot[146]=RemoveCamera `0x004882A0`；7 处对称帧分发循环同调。
- **防穿墙视距**：`40.0f`（`0x5A8E7C`，下界）+ `70.0f`（上界）配对；`5.0f`（`0x5A8F74`）为角速度平滑乘数及射线避让缓冲间距。

## 五、可复用核查清单

- **编号治理**：新建 `docs/` 文档前先 `ls docs/`（含非 `.md` 文件）；撞号后来者让位，让位后全量 `grep -rn` 修引用。
- **常量冲突**：同一常量在两文档给出不同定性 → 全镜像重扫定位唯一真身，双向互引。
- **派生脚本口径**：运行前确认版本参数（如 `u6_final_account` 须带 `v14`，裸跑默认 `v12` 旧口径）。
- **结论三态**：确认事实（落地地址）/ 推断（标注来源与置信）/ 未知（标 ❓）。❓ 未解密前不写定论。
- **隐私脱敏**：文档与脚本不含个人路径/用户名；一次性辅助脚本归档至私人库，不在工程内留副本。

## 六、方法论十二条（操作清单）

1. **`RET n` 参数元数裁决** + 自尾跳证伪律（候选导致调用方尾跳回自身死循环且无栈平衡，则结构不成立）。
2. **虚表共存性判定**：函数共存证实类成员归属；多虚表共享同一函数证实共享基类或转发路由。
3. **构造函数中的虚表写入**：多重继承下单一对象多张虚表指针，须结合 ctor 写入时机与 `this` 调整偏置确认基类。
4. **浮点/数学常数硬签名**优先于符号名（IEEE-754 常数 + QPC/DirectInput 等 Win32 API 锚点）。
5. **字符串只能作线索，绝不能作为结论**。
6. **汇编 listing 先于反编译器**；先读机器指令与操作码结构，再看伪代码。
7. **虚表槽位离开基址毫无意义**：须同时标基虚表地址 + 偏移字节 + 绝对 VA。
8. **按操作数形态而非偏移量消歧**：严格区分 `CALL dword ptr [...]` 与 `MOV`。
9. **单引用虚表槽位的 xref 盲区**：须反向索引虚函数表槽位定位调用源。
10. **偏移量本身不是唯一标识**：记完整 `base + index` + 绝对 VA；计数取全量扫描独立终值，禁引截断列表。
11. **被调用方 `RET n` 快速证伪调用点**：调用点未 push 参数而被调用方 `RET 4`，即推翻候选绑定。
12. **临近性不等于同一性**：`JMP [table]` 后的指令块未必是 case 0，须反查跳转表数组索引。
