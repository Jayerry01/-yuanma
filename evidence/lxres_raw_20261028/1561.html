值

model

查看道具

 

Model文件夹中的武器，道具，箱子等！

model="W0_0" # 武器的模型

model="Item01" # 道具的模型

name

hell

name = "hell"，接触有该属性的物品时直接死亡！

damage数字

name = "damage30"，接触有该属性的物品时每秒扣3点血量！

safe

name = "safe"，为截镖模式的出口

safeA

name = "safeA"，为截镖模式流星队的出口

safeB

name = "safeB"，为截镖模式蝴蝶队的出口

user01-16

name = " user01"， user01-16为盟主模式16个出生点！

声明时需要格式如下：

Object D_user01 # 盟主的出生点

{

  Position: 0.000 0.000 20.000 # 坐标 X Y Z。

  Quaternion: -1.000 0.000 0.000 0.000 # 方向 W X Y Z。

  TextureAnimation: 0 0.000 0.000

  Custom:

  {

    name="user01" # 出生点名称要与D_user01使用的序列相同。

  }

}#出生点后面必须有其它的物品

ObjectType

camerabox

ObjectType = camerabox#安全区，超出该物品范围强制死亡！

动画 需要把下面所有内容加入Custom{***}中

animation=sin#三角函数

deformref="xyz"#波动轴、可以x y z单独或组合使用

deformsize=30#幅度

deformfreq=.1#频率

deformrange=10#波大小
