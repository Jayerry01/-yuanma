常量

Rule

游戏模式

编号

说明

1

盟主，所有人死亡也不会自动结束！

2

劫镖，将镖物护送到指定位置！

3

护城，击毁指定城防！

4

暗杀，杀死敌对队长！

5

死斗，杀死敌对所有人！

注意：小于1和大于5的值均为死斗模式！

 

RoundTime

游戏时长，单位分钟！

PlayerSpawn

玩家入场时的出生点！出生点即为AI路径点，点击查看路径点详细说明！

PlayerSpawnDir

出生时的方向，单位角度！0度为正北方向！

PlayerWeapon

主武器，点击查看武器编号！

PlayerWeapon2

副武器，点击查看武器编号！

PlayerHP

显示血量*10

 

变量

Int

整数变量

String

字符串变量

Int x[x]

整数1维数组

 

函数

GameOver(±1)

提前强制结束游戏，正数为胜，负数为负！

 

事件

OnStart(){……}

游戏开始时执行，一般用于加载NPC！

OnUpdate(){……}

循环事件，游戏开始后一直循环执行！可用“return”强制结束内部事件！

 

自定义函数

函数名(参数){执行代码}

例如：

Jia(int c1,int c2){

       Return c1 + c2;

}

调用：

Jia(9,8);
