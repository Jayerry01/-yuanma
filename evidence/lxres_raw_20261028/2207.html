资料详情

文件在游戏目录下的pmodel文件夹中，文件名为PXX.POS（例如：p0.pos），每个pos文件对应一个人物mod，点击查看官方人物编号

可以使用文本编辑软件打开（列如：记事本）

文件打开后可以看到一些字符串，推荐使用big5编码打开文件，文件中有一些官方的繁体注释！注释符是#号！

 

文件中是一些pose片段，例如：

Pose 0

{

  source     1

  Start      1

  End        65

  LoopStart  1

  LoopEnd    65

}

 

以下为pose片段详解：

 

Pose xx {}

Pose名，xx为数字，查看官方pose编号

source

动作库源，0为character.amb公共库，1为pmodel中的私有库（例如：p0.amb）

Start

动作库中的开始帧

End

动作库中的结束帧

LoopStart

循环播放的开始帧（用于重复pose，如：站立，跑动）

LoopEnd

循环播放的结束帧（用于重复pose，如：站立，跑动）

EffectType

特效类型，好像没用

EffectID

特效ID，特效需要在effect.lst文件中录入

Link

链接pose，本pose播放完成后自动播放Link的pose

Action/Blend

行动/混合片段，作用暂未发现有差别，本文将统一解说

作用：主要用于加速或减速播放pose片段，Action/Blend片段中主要有三个参数：

 

start

开始帧（不能超出pose的开始帧）

end

结束帧（不能超出pose的结束帧）

speed

播放速度，数字越大播放速度越快

 

 

 

Attack

攻击，如果pose需要有攻击需要加上Attack
